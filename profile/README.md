## What Brave Search Brings to Web Discovery

Brave Search provides a web search experience designed to help users find information while placing an emphasis on privacy. It can be used independently or as part of a broader browser-based search workflow.

Search queries can be entered directly into the Brave Search interface, returning results organized around the requested subject. Search refinement can help narrow results when a query produces a broad range of information.

Brave Search can also be configured as a default search engine within compatible browser environments. This allows searches entered through browser address bars or search interfaces to use the selected search service.

Privacy-focused search can be useful for users who want to separate general web discovery from other browsing activity. The specific privacy behavior depends on the service and browser configuration being used.

Image search provides a dedicated way to discover visual material. It can be useful when the goal is to locate images rather than primarily text-based web pages.

Safe Search settings can help control the type of results displayed for particular searches. Available filtering levels can be adjusted according to the user's browsing requirements.

Search history management provides another aspect of organizing web discovery. Depending on the environment, users can review or manage their recent search activity through available controls.

Brave Search can also be used alongside the Brave browser. Browser search settings determine which search service handles searches initiated through the browser's search interface.

Search engine configuration is useful when switching between different search workflows. Users can review the default search engine and change it when their preferred search experience changes.

Search queries can be refined through more specific wording, additional context, or targeted terms. Clear queries generally make it easier to locate relevant information efficiently.

Brave Search and the Brave browser are related but distinct components. The browser provides the browsing environment, while Brave Search provides the search service used to discover web content.
